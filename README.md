# HJ3RAW ⚡

¡Bienvenido al repositorio **HJ3RAW**! Este espacio está dedicado al análisis, pruebas de equipamiento, monitoreo de bancos de baterías, electrónica aplicada e instrumentación industrial.

---

## 📌 Contenido del Repositorio

- **`docs/`**: Guías de medición, manuales de instrumentación y tablas de referencia para sistemas de energía.
- **`scripts/`**: Código y herramientas para adquisición de datos y monitoreo de baterías.
- **`schematics/`**: Diagramas de conexiones, circuitos y guías de pruebas eléctricas.

---

## 🛠️ Herramientas y Equipamiento

### Instrumentación
- **Multímetros digitales**: Pruebas de tensión ($V_{\text{DC}}$, $V_{\text{AC}}$), corriente y resistencia.
- **Sistemas de prueba de carga**: Verificación en reposo y bajo demanda para baterías de Plomo-Ácido, GEL y AGM.

### Sistemas de Almacenamiento Probados
| Tipo de Batería | Tensión Nominal | Tensión a Plena Carga | Rango de Uso Óptimo |
| :--- | :---: | :---: | :---: |
| **GEL / Deep Cycle** | $12\text{ V}$ | $12.8\text{ V} - 13.0\text{ V}$ | $12.2\text{ V} - 13.0\text{ V}$ |
| **Pila Alcalina (AA/AAA)** | $1.5\text{ V}$ | $1.58\text{ V} - 1.65\text{ V}$ | $1.30\text{ V} - 1.65\text{ V}$ |
| **LiFePO4 (4S)** | $12.8\text{ V}$ | $14.4\text{ V} - 14.6\text{ V}$ | $12.8\text{ V} - 14.4\text{ V}$ |
